# Nostalgic Startpage — Windows XP New Tab

Ностальгический рабочий стол Windows XP на каждой новой вкладке браузера. Ярлыки сайтов, папки, встроенные XP-приложения и игры, две темы оформления (Windows XP Luna и Mac OS X Aqua) — всё локально, без внешних серверов.

**В этом репозитории лежит готовое собранное расширение** — его можно установить сразу, без сборки.

## Установка

1. Скачайте репозиторий (Code → Download ZIP) или клонируйте его.
2. Откройте `chrome://extensions` (или `edge://extensions`), включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите корневую папку (где лежит `manifest.json`).
4. Откройте новую вкладку — появится рабочий стол XP.

Либо возьмите готовый ZIP со страницы [Releases](https://github.com/VibeCodeCrew/nostalgic_homepage_new/releases).

## Возможности

- **Рабочий стол**: три режима ярлыков (Плитки/Миниатюры/Ярлыки), папки, drag&drop, мультивыделение рамкой, скриншоты страниц, свои обои.
- **Темы**: Windows XP (Luna) и Mac OS X Aqua — строка меню, Dock с fish-eye увеличением, гелевые окна.
- **Меню «Пуск»**: каскадные «Все программы» как в настоящем XP, контекстные меню ярлыков со «Сменить категорию», настоящий MRU недавних программ, Log Off и Завершение работы.
- **Автогруппировка ярлыков** по категориям (словарь ~25 категорий, свои правила) — отдельно для Пуска и «Моих ярлыков».
- **Веб-приложения**: ярлык с галочкой «Открывать в окне» запускается в окне, оформленном под Internet Explorer 6.
- **Мой компьютер**: диск C: (ярлыки), диск D: (закладки браузера), Корзина, Сведения о системе.
- **Приложения**: Блокнот, WordPad, Paint, Калькулятор, Командная строка, Сапёр, Косынка, Червы, Пинбол «Космический Дед», DOOM (WASM, звук и музыка, автосейвы).
- **Прочее**: стикеры, скринсейвер «трубы», помощник Скрепка, BSOD-пасхалка, мастер первого запуска (OOBE), импорт/экспорт JSON, автообновления из релизов этого репозитория.

## Приватность

Все данные (ярлыки, настройки, скриншоты, сейвы DOOM) хранятся локально. Внешние запросы: фавиконки Chrome, скриншоты добавленных вами страниц, поисковые подсказки, проверка новой версии на GitHub.
