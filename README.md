# Nostalgic Startpage — Windows XP New Tab (модульный ребилд)

Ностальгический рабочий стол Windows XP на каждой новой вкладке браузера. Ярлыки сайтов, папки, встроенные XP-приложения и игры, две темы оформления (Windows XP Luna и Mac OS X Aqua) — всё локально, без внешних серверов.

Это **модульный ребилд** оригинального проекта ([VibeCodeCrew/windows_xp_homepage](https://github.com/VibeCodeCrew/windows_xp_homepage)): TypeScript + Vite, feature-oriented архитектура. Функциональность сохранена 1:1, данные пользователей оригинала подхватываются без миграции (те же ключи localStorage/chrome.storage).

## Возможности

- **Рабочий стол**: три режима ярлыков (Плитки/Миниатюры/Ярлыки), папки, drag&drop, мультивыделение рамкой, скриншоты страниц, свои обои.
- **Темы**: Windows XP (Luna) и Mac OS X Aqua — строка меню, Dock с fish-eye, гелевые окна.
- **Веб-приложения**: ярлык с галочкой «Открывать в окне» запускается в окне, оформленном под Internet Explorer 6.
- **Меню «Пуск»**: двухколоночное XP-меню, «Все программы» с папками, поиск, завершение работы.
- **Мой компьютер**: диск C: (ярлыки), диск D: (закладки браузера), Корзина, Сведения о системе.
- **Приложения**: Блокнот, WordPad, Paint, Калькулятор, Командная строка, Сапёр, Косынка, Червы, Пинбол «Космический Дед», DOOM (WASM, звук и музыка, автосейвы).
- **Прочее**: стикеры, скринсейвер «трубы», Clippy, BSOD-пасхалка, мастер первого запуска (OOBE), импорт/экспорт JSON, проверка обновлений с GitHub.

## Установка (готовая сборка)

1. Скачайте релиз или соберите сами (см. ниже).
2. Откройте `chrome://extensions` (или `edge://extensions`), включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → выберите папку `dist/`.
4. Откройте новую вкладку — появится рабочий стол XP.

## Разработка

Требуется Node.js 20+.

```bash
npm install
npm run build      # собрать расширение в dist/ (страница + service worker)
npm run watch      # пересборка страницы при изменениях
npm test           # vitest (core-модули)
npm run typecheck  # строгая проверка типов
```

После изменений — перезагрузить страницу новой вкладки; при изменении `src/background/` — кнопка Reload на карточке расширения.

Структура проекта и правила для ИИ-агентов — в `AGENTS.md`.

## Приватность

Все данные (ярлыки, настройки, скриншоты, сейвы DOOM) хранятся локально. Внешние запросы: фавиконки Chrome, скриншоты добавленных вами страниц, поисковые подсказки, проверка версии на GitHub.
